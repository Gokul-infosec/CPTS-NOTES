Oracle TNS

## Overview

Oracle Transparent Network Substrate (TNS) is a communication protocol used by Oracle databases and applications to communicate over a network.

TNS is part of Oracle Net Services and supports:

- Name resolution
- Connection management
- Load balancing
- Security
- TCP/IP communication
- IPv6
- SSL/TLS encryption

Oracle TNS is commonly found in enterprise environments such as:

- Healthcare
- Finance
- Retail
- Large enterprise infrastructures

tnsnames.ora

tnsnames.ora is used by Oracle clients to resolve service names to network addresses.

Example:

ORCL =
  (DESCRIPTION =
    (ADDRESS_LIST =
      (ADDRESS = (PROTOCOL = TCP)(HOST = 10.129.11.102)(PORT = 1521))
    )
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = orcl)
    )
  )

listener.ora

listener.ora is a server-side configuration file controlling the Oracle listener.

Example:

LISTENER =

    )
  )

Oracle SID

A System Identifier (SID) identifies a specific Oracle database instance.

The SID is important because clients use it when connecting to an Oracle database.

If an incorrect SID is supplied, the connection can fail.

Example:

SID = XE

Nmap Enumeration
Basic Oracle TNS Scan
sudo nmap -p1521 -sV <TARGET> --open

Example:

sudo nmap -p1521 -sV 10.129.205.19 --open

Example result:

1521/tcp open oracle-tns Oracle TNS listener 11.2.0.2.0 (unauthorized)
SID Enumeration

Nmap provides the:

oracle-sid-brute

NSE script.

Run:

sudo nmap -p1521 -sV <TARGET> --open --script oracle-sid-brute

Example:

sudo nmap -p1521 -sV 10.129.205.19 --open --script oracle-sid-brute

Example result:

| oracle-sid-brute:
|_  XE

Therefore:

SID = XE
Important Note About oracle-sid-brute

SID brute forcing can take a long time because the script tests many possible SIDs.

For example, a scan may remain around:

97.83% done

for several minutes.

If the target is an HTB lab and the script is taking unusually long, monitor it rather than repeatedly launching new scans.

ODAT
Oracle Database Attacking Tool

ODAT is an open-source Python tool designed to enumerate and test Oracle database security.

It supports modules for:

TNS communication
SID guessing
Service-name guessing
Password guessing
Database enumeration
Password hash retrieval
File operations
Privilege escalation
Command execution
Vulnerability checks
Installing ODAT

Install required packages:

sudo apt update
sudo apt install -y build-essential python3-dev libaio1

Clone ODAT:

git clone https://github.com/quentinhardy/odat.git
cd odat/

Install dependencies:

pip install python-libnmap
pip install pycryptodome
pip install openpyxl

SQL*Plus

SQL*Plus can be used to interact with an Oracle database.

Check the installed version:

sqlplus -v

Example:

SQL*Plus: Release 19.0.0.0.0 - Production
Version 19.6.0.0.0
SQL*Plus Connection

General syntax:

sqlplus <USER>/<PASSWORD>@<TARGET>/<SID>

Example:

sqlplus scott/tiger@10.129.205.19/XE
SYSDBA Connection

If the authorized account has sufficient privileges:

sqlplus <USER>/<PASSWORD>@<TARGET>/<SID> as sysdba

Example:

sqlplus scott/tiger@10.129.205.19/XE as sysdba

Successful connection:

Connected to:
Oracle Database 11g Express Edition Release 11.2.0.2.0

Key Takeaways
Oracle TNS commonly listens on TCP/1521.
Always identify the Oracle TNS version first.
The Oracle SID is critical for establishing a database connection.
oracle-sid-brute can identify valid SIDs but may be slow.
ODAT provides many Oracle enumeration modules.
passwordguesser can identify valid credentials.
SQL*Plus is useful for direct Oracle database interaction.
user_role_privs reveals the current user's database roles.
sys.user$ can contain Oracle password hashes when sufficient privileges exist.
Don't rely only on automated tools; understand what each module is actually doing.
