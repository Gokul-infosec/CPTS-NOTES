


# CPTS-NOTES

## CPTS Pentester Path — Practical Notes, Commands & Methodology

This repository contains my personal notes, commands, methodologies, and practical
learnings while developing hands-on penetration testing and offensive security skills.

The notes are created as part of my journey through the Hack The Box Academy
Pentester Path and hands-on security labs.

Develop practical penetration testing skills through hands-on learning and
structured security testing methodologies.
