# MSSQL Enumeration

## Overview

Microsoft SQL Server (MSSQL) is a relational database management system developed by Microsoft.

It is commonly found in Windows environments and integrates closely with Windows authentication and the .NET ecosystem.

MSSQL can expose valuable information during penetration testing, including:

- Server hostname
- MSSQL instance name
- SQL Server version
- Database names
- Authentication methods
- Named pipes
- Database contents
- Potentially dangerous configurations

MSSQL Information Enumeration
sudo nmap -sV -p1433 --script ms-sql-info <TARGET>

Instance name
TCP port
Named pipe
Cluster information

Example:

MSSQL NTLM Information

The ms-sql-ntlm-info NSE script can reveal Windows/NetBIOS information.

sudo nmap -p1433 --script ms-sql-ntlm-info <TARGET>

Useful information may include:

Target_Name
NetBIOS_Domain_Name
NetBIOS_Computer_Name
DNS_Domain_Name
DNS_Computer_Name
Product_Version

Example:

NetBIOS_Domain_Name: ILF-SQL-01
NetBIOS_Computer_Name: ILF-SQL-01
DNS_Domain_Name: ILF-SQL-01
DNS_Computer_Name: ILF-SQL-01

Therefore:

Hostname = ILF-SQL-01

MSSQL Authentication

MSSQL can use different authentication mechanisms.

When connecting to an authorized lab, make sure the authentication method matches the account provided.

Default MSSQL Databases

MSSQL commonly contains:

master
model
msdb
tempdb
master

Contains system-level information and server configuration metadata.

model

Template database used when creating new databases.

msdb

Used by SQL Server Agent and other SQL Server components.

tempdb

Temporary workspace used by SQL Server.

When performing enumeration, identify databases outside the normal default set.

Key Takeaways
MSSQL commonly uses TCP 1433.
ms-sql-info identifies MSSQL version and instance information.
ms-sql-ntlm-info can reveal Windows/NetBIOS hostname information.
MSSQL authentication method matters.
Impacket mssqlclient.py is extremely useful for MSSQL enumeration.
SELECT name FROM sys.databases; quickly identifies accessible databases.
Always distinguish default databases from custom databases.
Enumeration should build an attack-path picture rather than relying on a single scan.
